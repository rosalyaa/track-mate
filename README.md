<h1> 🖐️ AI Hand Gesture Controller: </h1>
  TrackMate is a Flutter-based web application that provides real-time college bus tracking for students and administrators. The system allows users to monitor bus locations, estimate arrival times, and improve daily commuting efficiency through an interactive Google Maps interface.
<br>

<h2> DEMO: http://localhost:52524 </h2>

<h2>1. Features</h2>

- Secure login and authentication
- Real-time bus location tracking
- Live bus route visualization
- Estimated Time of Arrival (ETA)
- Interactive Google Maps integration

<h2>4. Installation</h2>

Clone the repository: git clone https://github.com/rosalyaa/track-mate.git
<br>
Move into the project: cd track-mate
<br>
Activate it
<br>
(macOS/Linux): flutter run -d macos
<br>
(Windows): flutter run -d chrome
<br>
Install dependencies: pip install -r requirements.txt
<br>
Run the Project
<br>
http://localhost:52524



<h2>5. How It Works:</h2>
(a) Users log in securely using Firebase Authentication.
<br>
(b) Bus location data is updated and stored in Firebase realtime database.
<br>
(c) The application retrieves live location updates in real time.
<br>
(d) Google Maps displays the current bus location and route.
<br>
(e) Students can track buses and view the estimated arrival time (ETA), while administrators manage buses, routes, and driver information.
